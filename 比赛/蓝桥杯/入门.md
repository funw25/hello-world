## T4.【如何保留有效数字】

现在有 500 毫升的肥宅快乐水，要均分给 3 名同学，每位同学可以分到多少毫升？请输出一个数字作为输出。保留 6 位有效数字，且不使用科学计数法。

`cout << fixed << setprecision(3) << 500.0 / 3;`

* 保留 **k 位小数**（小数点后 k 位）

* `printf()` 格式:

  * 保留六位小数`printf("%.6f", 188.1234567);`
  * ` %.nf`的n是小数点后的个数
* `cout<<`格式：

  * `<<fixed`<<`setprecision(n)`
  * ```c++
    #include <iostream>
    #include <iomanip>
    using namespace std;

    double x = 166.6666;
    cout << fixed << setprecision(6) << x << endl;  // 6 位小数，输出 166.666667
    ```
* 保留 k 位**有效数字**（从第一个非零数字开始往后数 k 个）

  * `printf()` 格式：

    * 保留n位有效数字 `printf("%.ng", x)`;
    * `%.ng` 里的 n 是有效数字的个数指数太小（< -4）或太大（>= 精度）时，%g 就切到科学计数法。且会删掉末尾的0
  * `cout<<`格式：`setprecision(n)` 是有效数字n个

    ```C++
    #include <iostream>
    #include <iomanip>
    using namespace std;

    double x = 166.6666;
    cout <<  setprecision(6) << x << endl;  // 6 位小数，输出 166.666667
    ```

## T10【牛吃草问题】

洛谷的评测任务是单位时间内均匀增加的。**8** 台评测机 **30** 分钟可以刚好把评测队列中的程序评测完毕，**10** 台评测机 **6** 分钟可以刚好把评测队列中的程序评测完毕，请问几台评测机可以在 **10** 分钟时刚好把评测队列中的程序评测完毕？

### 牛吃草问题：

初始草量，草每天生长的量（设为未知数）

牛每天吃的量（认为是单位1），天数


本题为牛吃草问题的变题：

* 初始任务量 = 初始草量 A
* 每分钟新增任务 = 草生长 k
* 每个评测机每分钟处理的量 = 一头牛每天吃的量  认为是1

<法一>列二元一次方程

> 8×30=A+30k
> 10×6=A+6k
> 解得A和k
> 然后： 10×n=A+10k
> 解得n

<法二>瞪眼法（本题特殊）

> 8台机器30分钟
> ？台机器10分钟
> 10台机器6分钟
> 只能是9


## T12【字母转换】

大家都知道有 **26** 个英文字母，其中 A 是第一个字母。现在请编程求出：

1. M 是字母表中的第几个字母？
2. 第 **18** 个字母是什么？

输出一个数字和一个字母（大写字母），使用换行隔开。

### 背景知识：

* 在计算机里，字符的存储实际上是存储ASCII码：（注意''才是字符）
  * 'A' 到 'Z' 连续，65到90；
  * 'a' 到 'z' 连续，97到122;
  * 大小写差值 = 22
* 

### 一些常见题目：

1. 是第几个字符：**第几个 = '该字母' - 'A' + 1**
2. 第 n 个字母是什么：**字母 = 'A' + n - 1**

```C++
cout << char( 'A' + n - 1 ) << endl;  // 注意一定要进行强制类型转换

//或者：
char ans = 'A' + n-1 ;
cout << ans << endl;
```

3. 大小写转换：
   ```C++
   // 大写→小写
   char( '字母' + 32 );
   char c = 'A' + 32;

   // 小写→大写
   char('字母'-32);
   char c='字母' - 32;
   ```
