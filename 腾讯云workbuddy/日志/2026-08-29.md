# 2026-08-29

## 搭建「AI 早报 Agent」

用户需求：每天自动搜索过去 24 小时全球 AI 新闻，挑 6 条适合大学生看的（发生了什么 / 跟学生什么关系 / 来源链接），推送企业微信群 + 存到在线表格。风格要专业但不累。

### 交付物（目录 ai-daily/）
- `push.py` — md → 企业微信推送（按**条目边界**分段，非按行，避免切断单条新闻；限流 1.2s/条；同时追加 CSV 归档）
- `render_html.py` — md → 精美 HTML 阅读版（light/dark 自适应）
- `PIPELINE.md` — 工作流手册（检索源、筛选标准、写作模板、已知坑）
- `config.json` — 企业微信 webhook（当前是 PLACEHOLDER 占位，待用户填）
- `archive/2026-08-29.md` / `.html` / `sheet.csv` — 首期内容

### 关键决策
- 企业微信单条上限 4096 字节，脚本按 3800 切。最初按行切会切断第 4 条，改为按 item 块切（3+3 分段）。
- CSV 写入前用 `strip_md()` 清掉 `**`、列表符号，否则表格里全是 markdown 标记。
- 用户选择：**先跳过推送**（webhook 未配）、**每天 08:00**、归档表格。

### 待办 / 阻塞
- 企业微信 webhook 待用户提供，填进 `ai-daily/config.json` 或跑 `python push.py --save-webhook "URL"` 即可生效。
- **在线表格方案未落地**：WorkBuddy 资料库 skill 的 `connect_open_platform` 换票失败（HTTP 404），无法建在线表。当前退化为本地 `archive/sheet.csv`（UTF-8 BOM，可直接拖进 Excel/飞书/腾讯文档）。下次可重试资料库，或改用腾讯文档。

## 追加：用户不是群管理，机器人受阻

用户反馈**不是企业微信群管理员，加不了群机器人**（企业微信机器人只有群主/管理员能添加，普通成员不行）。

应对：
1. 给 push.py 加了 `--plain` 参数，导出纯文本版（`build_plain()` + `plain_block()`），用户手动复制粘贴到群里即可，兜底不依赖 webhook。文件：`archive/2026-08-29-纯文本.txt`（3474 字符）。
2. `strip_md()` 补了规则：清掉中文/中文标点之间的多余空格（markdown 换行留下的），否则粘贴出去很难看。
3. 告知用户三条路：找群主要 webhook / 自己建群当群主 / 手动粘贴。**一个 webhook 只绑一个群**，换群要重建机器人。

### 企业微信 markdown 渲染限制（已写进 PIPELINE.md）
推送过去是**卡片式文本消息，不是表格**。支持 `# 标题`/`**粗体**`/`[链接]`/`> 引用`/`<font color>`；**不支持表格和图片**；`- ` 列表不会渲染成圆点（所以渲染器统一转 `·`）。单条上限 4096 字节。
